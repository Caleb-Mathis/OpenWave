# OpenWave

OpenWave is an offline messaging platform that allows any device with a microphone and speaker to communicate via audible or ultrasonic waves. 

## Features Included

- Ultrasound & Audible Modes
- Message Volume & Rate Settings
- Encryption & Contacts
- Sleek iOS 27-style UI
- iOS & Android Haptics *(WiP)*
- Light & Dark Themes
- Bubble Color Customization
- A Fancy Spectrogram
